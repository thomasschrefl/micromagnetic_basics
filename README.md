# micromagnetic_basics
basic micromagnetics with python

## energy of a uniformly magnetized particle
`sw.ipnb` computes the energy of a small particle as function of field angle

## hysteresis loop of a uniformly magnetized particle 
`loop.ipnb` computes the hysteresis loop of a small particle as function of field angle

## domain wall
`wall.ipnb` computes the domain wall profile
