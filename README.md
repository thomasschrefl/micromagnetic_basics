# micromagnetic_basics
basic micromagnetics with python

## energy of a uniformly magnetized particle
The file `sw.ipnb` computes the energy of a small particle as function of field angle

## hysteresis loop of a uniformly magnetized particle 
The file `loop.ipnb` computes the hysteresis loop of a small particle as function of field angle

## domain wall
The file `wall.ipnb` computes the domain wall profile
